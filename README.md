# Pradyumn Bhushan's portfolio

A static HTML, CSS, and JavaScript website for [pradyx.github.io](https://pradyx.github.io/), compatible with GitHub Pages.

Run the local preview:

```sh
./start.sh 8000
```

Open [http://127.0.0.1:8000/](http://127.0.0.1:8000/) and keep the server running while testing. No install or build step is needed.

`files/resume.pdf` is the only source of personal and professional facts. Existing portfolio projects are preserved; additional resume projects share the original image gallery and its filters. App logos and screenshots are saved locally from their Play Store listings, with asset provenance in `images/portfolio/sources.json`. See `AGENTS.md` for content and preservation rules.

`files/cv.pdf` is a three-page CV derived from the resume, covering the professional profile, skills, education, detailed experience, and all thirteen resume projects. Its links retain the resume destinations and download counts. The phone number is omitted. About offers Download Resume and Download CV side by side, wrapping on smaller screens. When the resume changes, regenerate and visually check the CV from that source.

The Obsidian project map and linked notes are in `/Users/prady/Vault/Projects/pradyx.github.io/Project Map.md`.
